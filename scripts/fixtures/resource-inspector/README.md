Generated with `python3 -B scripts/test-resource-inspector.py --prepare`.
Verify with `python3 -B scripts/test-resource-inspector.py --verify`.

These are **raw public evidence projections, not the new bridge wire contract**.
Timing/electrical arrays in projections retain only their first two original entries;
`fixture_original_count` records the source count. Full immutable evidence remains
in the example checkout and is hash-bound by `manifest.json`. Raw selected native
report spans are retained separately in `byte-oracles.json` with full-source hashes.

`failed-evidence.json` comes from a historical disposable semantic-negative test;
it is not another real SRAM execution. Flops/fallback are retained emitted manifests,
not proof of their synthesis/physical realization. FIFO is preparation inventory,
not a verified emitted bundle. A complete FIFO bundle still needs locating/verifying
through A's concrete bundle API before bundle acceptance can pass.

Preparation records the 276 historical and 333 augmented file hashes, app configuration,
existing current-pointer targets/timestamps and the immutable PT5b companion identities.
It performs no emission, build, provider execution, Git or daemon action.

private synthetic roots. `--smoke` checks its failed/corrupt/stale/unsupported/budget
and genuinely delayed old-generation behavior without starting Workbench. Its opaque
artifact IDs and byte oracles are synthetic, not claims about actual run sources.
Native HTTP, synthetic late-target PTY and retained real bridge HTTP/PTY acceptance
have now run. See `docs/resource_inspector_acceptance.md` for exact captured versions,
passing receipts, retained failed attempts and the independent-review boundary.
